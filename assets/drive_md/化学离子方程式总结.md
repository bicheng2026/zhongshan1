# 化学离子方程式总结

化学离子方程式总结

氢氧化铜与酸反应：Cu(OH)₂ + 2H⁺ → Cu²⁺ + 2H₂O （错误原因：Cu(OH)₂ 是沉淀，不能拆为 OH⁻）

氢氧化钡与硫酸反应：Ba²⁺ + 2OH⁻ + 2H⁺ + SO₄²⁻ → BaSO₄↓ + 2H₂O （错误原因：遗漏 BaSO₄ 沉淀）

氢氧化钠与硫酸反应：H⁺ + OH⁻ → H₂O

硝酸钡与硫酸：Ba²⁺ + SO₄²⁻ → BaSO₄↓

氯化钡与硫酸钠：Ba²⁺ + SO₄²⁻ → BaSO₄↓

碳酸钡与硫酸：BaCO₃ + 2H⁺ + SO₄²⁻ → BaSO₄↓ + CO₂↑ + H₂O（原因：BaCO₃ 不溶，且生成 CO₂）

氯化钡与硫酸：Ba²⁺ + SO₄²⁻ → BaSO₄↓

可能为 CaCl₂ 与 Na₂CO₃ 反应：Ca²⁺ + CO₃²⁻ → CaCO₃↓

可能为澄清石灰水与 K₂CO₃ 反应：Ca²⁺ + CO₃²⁻ → CaCO₃↓

碳酸钙与盐酸：CaCO₃ + 2H⁺ → Ca²⁺ + CO₂↑ + H₂O （错误原因：CaCO₃ 不能拆）

碳酸氢钠与硫酸：  HCO₃⁻ + H⁺ → CO₂↑ + H₂O  （错误原因：HCO₃⁻ 不能拆为 H⁺ + CO₃²⁻）
