# 碳酸氢钠与盐酸反应

碳酸氢钠与盐酸反应：

HCO₃⁻ + H⁺ → CO₂↑ + H₂O

少量 CO₂ 通入澄清石灰水：

Ca²⁺ + 2OH⁻ + CO₂ → CaCO₃↓ + H₂O

钠投入水中：

2Na + 2H₂O → 2Na⁺ + 2OH⁻ + H₂↑

氯气溶于水：

Cl₂ + H₂O → 2H⁺ + Cl⁻ + ClO⁻

（错误原因：HClO 不能拆，应为 Cl₂ + H₂O ⇌ H⁺ + Cl⁻ + HClO）

氢氧化钡与过量硫酸氢钠反应：

Ba²⁺ + 2OH⁻ + 2H⁺ + SO₄²⁻ → BaSO₄↓ + 2H₂O

检验亚铁离子：

Fe²⁺ + [Fe(CN)₆]³⁻ → Fe₃[Fe(CN)₆]₂↓

（非离子方程式，实际为络合反应）

小苏打与稀盐酸反应：

HCO₃⁻ + H⁺ → CO₂↑ + H₂O

氢氧化钡与稀硫酸反应：

Ba²⁺ + 2OH⁻ + 2H⁺ + SO₄²⁻ → BaSO₄↓ + 2H₂O

碳酸钙与盐酸反应：

CaCO₃ + 2H⁺ → Ca²⁺ + CO₂↑ + H₂O

氢氧化钠与盐酸反应：

H⁺ + OH⁻ → H₂O

铜与稀硫酸（不反应）

氢氧化镁与盐酸反应：

Mg(OH)₂ + 2H⁺ → Mg²⁺ + 2H₂O

铜与硝酸银溶液反应：

Cu + 2Ag⁺ → Cu²⁺ + 2Ag

（错误原因：电荷守恒，但未配平原子）

小苏打与盐酸反应：

HCO₃⁻ + H⁺ → CO₂↑ + H₂O

氨水与盐酸反应：

NH₃·H₂O + H⁺ → NH₄⁺ + H₂O

3Fe + 8H⁺ + 2NO₃⁻ → 3Fe²⁺ + 2NO↑ + 4H₂O

（错误原因：过量铁应生成 Fe²⁺）

二氧化硫通入溴水：

SO₂ + Br₂ + 2H₂O → 4H⁺ + 2Br⁻ + SO₄²⁻

SiO₃²⁻ + 2H⁺ → H₂SiO₃↓

（错误原因：石灰乳不拆）

MgCO₃ + 2H⁺ → Mg²⁺ + CO₂↑ + H₂O

（错误原因：MgCO₃ 微溶，但可拆）

钠与水反应：

2Na + 2H₂O → 2Na⁺ + 2OH⁻ + H₂↑

过量试剂：生成酸式盐/络合物（如过量CO₂通NaOH）
