# 终极总结

终极总结（100题全覆盖）

1. 四大高频反应：

碳酸盐与酸：CaCO₃ + 2H⁺ → Ca²⁺ + CO₂↑ + H₂O

氯气歧化：Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O

钠与水：2Na + 2H₂O → 2Na⁺ + 2OH⁻ + H₂↑

硝酸与金属：3Cu + 8H⁺ + 2NO₃⁻ → 3Cu²⁺ + 2NO↑ + 4H₂O

2. 三大易错点：

弱电解质不拆（醋酸、氨水、次氯酸）

沉淀/氧化物不拆（CaCO₃、Fe₂O₃、Cu(OH)₂）

电荷守恒（如 Fe + 2Fe³⁺ → 3Fe²⁺ 错误 → Fe + 2Fe³⁺ → 3Fe²⁺ 正确）

3. 两类定量反应：

少量试剂：按不足量物质配平（如少量CO₂通石灰水）

过量试剂：生成酸式盐/络合物（如过量CO₂通NaOH）

一、不能拆的物质

1. 弱电解质：

弱酸：CH₃COOH（醋酸）、H₂CO₃（碳酸）、HClO（次氯酸）、H₂S（氢硫酸）、HF（氢氟酸）

弱碱：NH₃·H₂O（一水合氨）、Fe(OH)₃（氢氧化铁）、Cu(OH)₂（氢氧化铜）、Mg(OH)₂（氢氧化镁）

水：H₂O

难溶物（沉淀）：

CaCO₃（碳酸钙）、BaSO₄（硫酸钡）、AgCl（氯化银）、Fe(OH)₃、Cu(OH)₂、Mg(OH)₂、BaCO₃（碳酸钡）

特殊：CaSO₃（亚硫酸钙）、FeS（硫化亚铁）

3. 单质和氧化物：

金属单质：Fe、Cu、Zn

非金属单质：Cl₂、Br₂

氧化物：Fe₂O₃（氧化铁）、CuO（氧化铜）、MgO（氧化镁）、Na₂O₂（过氧化钠）

4. 微溶物（视情况）：

作反应物且为悬浊液时不拆：Ca(OH)₂（石灰乳）、MgCO₃（碳酸镁）

作生成物时写沉淀符号：CaSO₄（硫酸钙）

5. 其他：

酸式盐中的弱酸根：HCO₃⁻（碳酸氢根）、HSO₃⁻（亚硫酸氢根）

络合物：[Ag(NH₃)₂]⁺（银氨离子）、Fe(SCN)₃（硫氰化铁）

二、注意事项

1. 拆分原则：

强酸、强碱、可溶性盐拆成离子；弱电解质、沉淀、单质、氧化物不拆。

微溶物（如Ca(OH)₂）澄清溶液可拆，浊液不拆。

2. 配平三守恒：

质量守恒：左右原子种类和数量相等。

电荷守恒：左右电荷代数和相等（如Fe³+ Cu → Fe²+ Cu²错误，应为2Fe³⁺ + Cu → 2Fe²⁺ + Cu²⁺）。

电子守恒：氧化还原反应中得失电子数相等。

反应物用量：

少量/过量影响产物（如CO₂通入Ca(OH)₂少量生成CaCO₃过量生成Ca(HCO₃)₂）。

定量反应按比例书写（如Ba(OH)₂ + NaHSO₄比例不同方程式不同）。

特殊反应条件：

加热、电解、光照等需标注（如MnO₂ + 4H⁺ + 2Cl⁻ → Mn²⁺ + Cl₂↑ + 2H₂O需加热）。

5. 物质状态：

固态物质（如CaCO₃）不拆，气态生成物标↑（如CO₂↑）。

三、常出现的易错点

1. 弱电解质误拆：

醋酸写为H⁺（正确：CH₃COOH + OH⁻ → CH₃COO⁻ + H₂O）。

次氯酸写为ClO⁻（正确：Cl₂ + H₂O ⇌ H⁺ + Cl⁻ + HClO）。

2. 沉淀/氧化物误拆：

Cu(OH)₂写为OH⁻（正确：Cu(OH)₂ + 2H⁺ → Cu²⁺ + 2H₂O）。

Fe₂O₃写为Fe³⁺（正确：Fe₂O₃ + 6H⁺ → 2Fe³⁺ + 3H₂O）。

3.电荷/质量不守恒：

Fe + 2Fe³⁺ → 3Fe²⁺（正确），误写为Fe + Fe³⁺ → 2Fe²⁺（电荷不等）。

Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O（正确），误漏H₂O。

4. 忽略反应物用量：

CO₂通入NaOH：少量生成CO₃²⁻，过量生成HCO₃⁻。

NaHCO₃ + Ca(OH)₂：少量Ca(OH)₂生成CaCO₃，过量生成CaCO₃ + H₂O。

5. 混淆离子共存：

Ca²⁺与CO₃²⁻生成沉淀，不能共存（如CaCl₂ + CO₂不反应）。

H⁺与HCO₃⁻生成气体（如NaHCO₃ + HCl → CO₂↑）。

6. 氧化还原反应错误：

Cu + H⁺（不反应，因Cu不活泼）。

Fe + HNO₃（稀）：生成Fe²⁺，非Fe³⁺。

四、涉及的离子方程式列举（100题全覆盖）

1. 基础反应：

CH₃COOH + OH⁻ → CH₃COO⁻ + H₂O（醋酸与碱）

Cu(OH)₂ + 2H⁺ → Cu²⁺ + 2H₂O（氢氧化铜与酸）

Ba²⁺ + SO₄²⁻ → BaSO₄↓（钡盐与硫酸盐）

2. 碳酸盐相关：

CaCO₃ + 2H⁺ → Ca²⁺ + CO₂↑ + H₂O（碳酸钙与酸）

CO₂ + 2OH⁻ → CO₃²⁻ + H₂O（少量CO₂与碱）

CO₂ + OH⁻ → HCO₃⁻（过量CO₂与碱）

3. 氧化还原反应：

2Fe³⁺ + Cu → 2Fe²⁺ + Cu²⁺（刻蚀铜板）

Cl₂ + 2Fe²⁺ → 2Cl⁻ + 2Fe³⁺（氯气氧化亚铁）

3Cu + 8H⁺ + 2NO₃⁻ → 3Cu²⁺ + 2NO↑ + 4H₂O（铜与稀硝酸）

4. 酸式盐反应：

HCO₃⁻ + H⁺ → CO₂↑ + H₂O（小苏打与酸）

HCO₃⁻ + OH⁻ → CO₃²⁻ + H₂O（碳酸氢钠与碱）

5. 特殊反应：

Al(OH)₃ + OH⁻ → AlO₂⁻ + 2H₂O（铝的两性）

SiO₂ + 2OH⁻ → SiO₃²⁻ + H₂O（硅酸盐）

2Al + 2OH⁻ + 6H₂O → 2AlO₂⁻ + 3H₂↑（铝与强碱）

6. 易错方程式修正：

误：Fe + 2H⁺ → Fe³⁺ + H₂↑ → 正：Fe + 2H⁺ → Fe²⁺ + H₂↑

误：Ca²⁺ + CO₂ + H₂O → CaCO₃↓ + 2H⁺ → 正：Ca²⁺与CO₂不反应

误：Cl₂ + H₂O → 2H⁺ + Cl⁻ + ClO⁻ → 正：Cl₂ + H₂O ⇌ H⁺ + Cl⁻ + HClO
